# Transaction Anomaly Detection

## Overview
This project identifies unusual transaction patterns
using the Isolation Forest machine learning algorithm.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Algorithm
Isolation Forest

## Model Configuration
- Number of estimators: 200
- Random state: 42

## Project Structure
- data/: Transaction dataset
- ananomy_detection.ipynb: Model development notebook
- abnormal_model.pkl: Trained model
- requirements.txt: Project dependencies

## Installation

Install dependencies:

pip install -r requirements.txt

## How to Run
1. Clone this repository.
2. Install dependencies.
3. Ensure the dataset is available in the data folder.
4. Open the notebook in Jupyter.
5. Run the notebook cells.
